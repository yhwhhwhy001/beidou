## 4. Phase 3 · Problem Research

### 4.1 Problem Statement

操作者（唯一用户）在 demo 实盘面板上看到成交稀少（最近 36 小时 1–2 单/天，7 天均值 4.3），把它读成「系统慢」。可观察损失：无——当前构造 8 天的归因 P&L 为负但在噪声内（z −1.6）。不解决的后果：操作者对系统的信心与耐心下降，可能在窗口外手改构造（RISK-FQ01）；以及每个安静日再触发一轮研究（8 天内已两次：D-039 与本文，K-FQ12）。

### 4.2 Causal Chain（症状 → 根因 → 可干预杠杆）

```
每小时一周期（1h bar，E-FQ03）
→ tsmom 三个 horizon = 7/14/30 天，且只取方向（E-FQ07/08）→ 目标权重每小时只做微调，翻转中位 17 次/币·年

→ 稳态 4.3 单/天，回测预测 4.6（E-FQ05）
```

根因是设计：**方向信号 + 宽带 + 慢波动率估计**这三件事各自都被独立检验证明比更快的替代赚得多（E-FQ06/07/25）。可干预杠杆按层：执行层（带、bar）——已定价且为负；信号层（horizon、新书）——短 horizon 已否决，新书需自己的证据与自己的预登记；组合层（`vol_target`、universe 宽度）——前者预算封顶且 P26 方向向下，后者未测且受绝对臂约束。

限定：这是同一个信号的曲线；0.40 那一点是确认性的（K-FQ01），但 0.50 → 0.00 的**单调下降是一条曲线不是一个点**；「占毛利」列只有两位有效数字，边际值 ±5 bps 内是噪声。
