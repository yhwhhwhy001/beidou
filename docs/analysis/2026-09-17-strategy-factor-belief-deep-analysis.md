## 4. Phase 3 · Problem Research

### 4.1 Problem Statement

操作者观察到「九个策略族只活一个」，用一条信念解释它：策略都有用，缺的是因子。这条信念的问题不在它乐观，在它**把所有失败归到同一个不可观测的原因上**，于是每次失败都指向同一个动作（再搜），而这个动作在本仓库有可量的价钱；更糟的是，它把两条已经写好的、便宜的药方（时间止损、事件化）挡在视野之外，因为它们不是「因子」。要做的是把「不成功」拆开，看每一种能不能被信念解释、该配什么动作。

### 4.2 三个框定，以及为什么选 F2

#### 4.2.1 F1 的直接回答：把信念拆成三句

**第一句「任何策略都有用」——作为全称命题不可判；作为「已测形式下」的命题，否。** **[R 修订，K-SF01/K-SF02]** 冻结稿原句是「作为全称命题，否」，理由是一个结构论证：只做门控（缩仓、开关、缩短持有）的因子，产出的是原策略持仓的子集，组合收益是原策略在各状态下条件收益的加权平均，全 ≤ 0 时任何门救不了。这个论证的形式对，前提没有证据：「每个 ex-ante 可观测状态下条件收益 ≤ 0」在报告里只对两类状态有数——5 个日历 fold 与 `trend_gate_z ∈ {1.5, 2, 3}`（09-04 的 27 格，全负）；按波动率分位拆的条件 Sharpe 有现成函数（`regime_split_sharpes`）而零调用者（E-SF19）。而「持仓年龄 ≤ 4 bar」这个 ex-ante 状态，仓库量过，条件收益为正（E-SF17：meanrev 1h/4h IC t 6.8 / 3.8）。挖掘那 2,073 行也关不掉这一支：它们是独立信号，不是「meanrev 在状态 X 下」，而且挖掘语法里没有比较、阈值、指示函数或取号算子（RESEARCH_LOG 09-09 复核节原文），离散门控根本不在搜索空间里。所以本仓库能证明的是：**日历状态、三档趋势门、连续乘法 regime 门、独立表达式，这四种形式下「加因子」救不了 meanrev / breakout**；能救它们的，按仓库自己的诊断，是持有期与事件化——那不是因子，是形式化（§7 ⑤）。

**第二句「只要与特定因子结合就会产生正向收益」——样本内永真，样本外是待检验假设。** 样本内：给定有限数据，条件变量的空间足够大，总能找到一个让任何 P&L 序列为正的划分（E-SF16 第一条是这个事实的定量版本）。这不是信念的支撑，是信念的**病**：DSR、D-028 的分位数门、trials ledger、预登记，全都是为了不让「找到了」被「搜够了」冒充。样本外：本仓库的有界搜索（676 个 1h 表达式，E-SF05）在纯噪声下的期望最好成绩（门 1.785）已经高过我们真实持有的最好的书（1.585）；唯一过门的 `594a12f9` 在 book 层挂了三次，headroom 又被后续搜索吃掉四分之三。样本外唯一的正例是 E-SF09：约 +0.1。

**第三句「不成功是因为没挖到因子」——不可证伪。** 它的结构是「治疗有效，无效说明剂量不对」。A6 要求每个 P0 命题写出什么观察能否定它；这一句写不出来。它不是错，是**没有内容**——直到把它改写成「不成功是因为 X，X 可以这样查」为止。§7 给了五个 X。

#### 4.2.2 F3 为什么让信念感觉对

如果「因子」指的是信号源本身（R2 读法：策略 = 入场 / 出场 / 定尺寸的壳，因子 = 壳里装的信息），那信念说的是「任何壳装上有信息的因子都能赚钱」。E-SF08 支持它的一半：edge 确实来自信号，构造是放大器。但另一半不成立：壳不是无害的——同一个信号，`equal_notional` 壳 0.91、full 壳 1.72、`constant_long` 壳 0.10；meanrev 的壳把一个 1h/4h IC t 6.8 的 z 分数变成了 −2.29（E-SF17 / E-SF02）；residual 换一组参数成本占比从 56% 变 11%（E-SF20）。而且在这个读法下，「有用」的是因子不是策略，信念的主语换了。两种读法殊途同归：**有用的是信息；策略与因子哪个叫什么，不改变「信息在不在、够不够付成本、是不是 incumbent 已经持有、壳有没有把它杀掉」这四个问题。**

**D-SF01 · 推荐：把信念改写成下面这句，并让它带 Falsifier。**

> 一个策略是一条关于「谁在为什么付钱」的假设。它有用，当且仅当它携带 ex-ante 可得的信息（样本外 IC ≠ 0），这份信息在扣费后仍为正，且不是在跑的书已经持有的。因子能做三件事——选择机制何时活跃、决定仓位大小、提供分散——但**不能制造策略本身没有的信息**；壳（持有期、再平衡、退出）能把信息杀掉，也能把它放大。不成功有五种可具名的原因（§7），每种有自己的检验；「因子还没找到」只有在能说出那个因子应当追踪什么机制、并预登记之后，才算一种原因。

Falsifier：若某个族在死因 ①「无信息」下被归档（pit 上信号级 IC 不显著、门 0.00 仍不过 0.5 线、CPCV 负路径 > 10%），之后有人用一个**预登记的、有机制的**因子把它在 pit universe 上救过 D-020 / D-028 与 corr < 0.5 三道门，本句的「不能制造信息」即被否定，改写版本退回 Need Evidence。

胜出理由：它保留了原信念的内核（信息决定一切；有些失败是证据问题），去掉了不可证伪的那一句，补上了信念看不见的那一格（壳），并且零成本。放弃 O-SF0 的理由见 C-SF03 / C-SF04。关键成立条件：§7 的分流表对九个族都能填（A-SF02）。偏差自检：本文最可能受**确认偏差**影响——仓库两周来的叙事就是「否决有效、供给不是瓶颈」（P17、09-14），作者容易顺着它写；**审查证实这个偏差确实起了作用**（冻结稿把书级 FAIL 读成信号级「无信息」，K-SF01）。对策：E-SF09 的正例入表并写出量级；C-SF02 / C-SF07 判 SUPPORTED，不跟着「全部 REFUTED」走；§7 边界族两格都标。
