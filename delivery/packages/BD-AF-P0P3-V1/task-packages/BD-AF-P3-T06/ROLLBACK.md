# Rollback — PIT lineage and OOS seal

No accepted evidence may be downgraded to an unsealed or mutable representation.

1. Stop new promotion decisions; retain research-only access behind an explicit non-promotable status.
2. Preserve all manifests, seal events, and access logs as immutable evidence.
3. Select the prior research reader only for non-promotable characterization.
4. Prove every artifact created by the new path remains detectable and marked invalid if its lineage/seal cannot be verified.

Rollback fails if old code can promote unbound results, audit events disappear, OOS is reopened without invalidation, or immutable inputs are rewritten.
